# SaúdeVax | Controle de Vacinas

## Visão Geral
SaúdeVax é um sistema para gerenciar pacientes, vacinas e aplicações em um posto de saúde. Ele oferece funcionalidades como cadastro de pacientes, controle de estoque de vacinas e registro de aplicações.

## Funcionalidades
- Cadastro de pacientes.
- Controle de vacinas e estoque.
- Registro de aplicações.

## Requisitos
- **Backend**: Java com JDBC.
- **Banco de Dados**: MySQL.
- **Frontend**: HTML, CSS e JavaScript.
