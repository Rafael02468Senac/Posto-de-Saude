# Estratégia de Testes

## Tipos de Testes
- **Testes Unitários**: Validar métodos individuais.
- **Testes de Integração**: Garantir que os módulos funcionem juntos.
- **Testes de Aceitação**: Validar os fluxos principais do sistema.

## Ferramentas
- Não identificado no momento. Sugere-se o uso de JUnit para testes em Java.

## Cobertura Recomendada
- Cadastro de pacientes.
- Registro de vacinas.
- Controle de estoque.
