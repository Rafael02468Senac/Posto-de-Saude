# Requisitos do Sistema

## Funcionais
- Cadastro de pacientes com CPF único.
- Controle de estoque de vacinas.
- Registro de aplicações de vacinas.

## Não Funcionais
- Interface responsiva.
- Persistência de dados em MySQL.
- Suporte a múltiplos usuários simultâneos.

## Regras de Negócio
- Não permitir cadastro de vacinas vencidas.
- Bloquear aplicações de vacinas sem estoque.
